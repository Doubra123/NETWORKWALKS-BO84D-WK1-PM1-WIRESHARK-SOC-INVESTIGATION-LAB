# Wireshark SOC Investigation Labs

## Project Overview

This repository contains my work from six Wireshark-based SOC investigation labs completed as part of the Networkwalks Cybersecurity Internship (Week 1 – Extra Module).

The exercises provided an opportunity to explore network traffic, investigate suspicious activities and understand how Wireshark can be used during security investigations.

## Tools Used

- Wireshark
- Browser-based Wireshark Labs
- Network Packet Capture (PCAP) Analysis

## Labs Completed

| Lab | Investigation |
|---|---|
| [Lab 3: Identify the Attacker's IP](./LAB-3-ATTACKER-IP/) | Identifying suspicious IP addresses |
| [Lab 4: Follow TCP Stream 1](./LAB-4-TCP-STREAM-1/) | Analysing TCP communication |
| [Lab 5: Follow TCP Stream, Part 2](./LAB-5-TCP-STREAM-2/) | Further TCP stream investigation |
| [Lab 6: HTTP Plain Text Credentials](./LAB-6-HTTP-CREDENTIALS/) | Investigating exposed credentials |
| [Lab 7: Catch the Brute Force Attacker](./LAB-7-BRUTE-FORCE/) | Identifying suspicious login attempts |
| [Lab 8: Catch the Call Scammer](./LAB-8-VOIP-SCAM/) | Investigating VoIP communication |

## Skills Practised

Through these exercises, I gained practical experience with:

- Network traffic analysis.
- IP address identification.
- TCP stream investigation.
- HTTP traffic analysis.
- Recognising exposed credentials.
- Identifying brute-force activity.
- Investigating VoIP traffic.

## Key Takeaway

These labs helped me develop a better understanding of how network traffic can be examined to identify suspicious activities and support security investigations.

They also gave me an opportunity to practise thinking through network evidence rather than simply relying on theoretical knowledge.
